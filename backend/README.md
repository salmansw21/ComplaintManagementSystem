# Complaint Management Backend

Java 17, Spring Boot 3.5.6, Spring Web, JPA/Hibernate, MySQL, Spring Security, JWT, Bean Validation and Lombok.

## Requirements
- JDK 17+
- Maven 3.9+
- MySQL 8+

## Run
Create/use MySQL with root password `root` or change `application.properties`, then run `mvn spring-boot:run`. API: http://localhost:8080

Demo accounts are created automatically on an empty database. See root README.
